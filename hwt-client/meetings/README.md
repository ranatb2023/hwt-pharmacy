# Meeting notes

One file per conversation, named `YYYY-MM-DD-topic.md`. Write it the same day.

**Every decision recorded here must also be copied into the decision log in
[`../../hwt-core/STATUS.md`](../../hwt-core/STATUS.md).** That log is what stops the same
conversation happening twice.

A useful note records: who was there, what was decided, what was *not* decided, and what we
committed to do next. It does not need to be long.
